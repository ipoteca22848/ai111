# StreamForge Studio

Windows-приложение по сценарию из видеореференса: **запись стрима или ссылка → моменты → вертикальные клипы → субтитры и рекламный баннер → MP4**.

Это новый проект вместо прежнего AI Clip Studio. Предыдущий код сохранён в ветке `archive/stage-one-v0.1.1`; рабочие модули заменены.

## Скачать Windows EXE

[StreamForgeStudio.exe — готовые сборки](https://github.com/ipoteca22848/ai111/releases/latest)

Windows 10/11 x64. EXE включает Python, FFmpeg, шрифт с кириллицей и многоязычную модель **Whisper Tiny**. Для локального видео интернет не нужен. На первом запуске распаковка занимает время; требуется свободное место в TEMP. Администраторские права не нужны. Файл не имеет цифровой подписи. Контрольная сумма публикуется рядом с EXE.

## Как пользоваться

1. Выберите видео или вставьте ссылку YouTube / Twitch VOD.
2. Выберите число клипов (1–20), длительность (до 10–180 секунд), язык и CPU либо CUDA.
3. Настройте формат 9:16, субтитры, заголовок и свой текстовый/графический баннер.
4. Нажмите **«Создать клипы»**. Дождитесь анализа и экспорта.
5. Выберите клип для предпросмотра. Кнопка «Открыть папку клипов» покажет готовые MP4.
6. Настройки можно сохранить как шаблон; отмеченные клипы — повторно экспортировать с новым оформлением.

Готовые файлы сохраняются в выбранной папке в подпапках `StreamForge-XXXX`. Повторный экспорт создаёт новую версию и сохраняет предыдущую. Исходное видео никогда не перезаписывается.

## Реализовано

- Локальный импорт и загрузка поддерживаемых записей YouTube/Twitch через yt-dlp с реальным прогрессом, скоростью и ETA.
- Многоязычное распознавание речи **faster-whisper / CTranslate2**, тайминги слов; CPU int8 по умолчанию.
- Анализ RMS звука по секундам, движения/смен кадров и плотности речи, словесных реакций; объяснимый относительный score 0–100.
- Отбор разных временных участков с ограничением пересечений; предпочтение ближайших окончаний фраз.
- Три вертикальных режима: размытый фон, центральный кроп и вписывание с чёрным фоном.
- H.264/AAC MP4, 720×1280 или 1080×1920, 30/60 FPS; реальный прогресс FFmpeg.
- Кириллические субтитры с караоке-подсветкой, заголовок первых пяти секунд.
- Текстовый баннер с градиентом и собственное изображение/логотип; сохранение шаблона.
- Встроенный плеер, прокрутка позиции, история задач, SQLite, фоновая обработка, отмена и повторный экспорт.
- EXE проходит автоматический тест распознавания настоящей речи из контрольной записи и полного экспорта, а также запуска GUI.

## Практические ограничения

- Поиск моментов — эвристика по реальным сигналам, а не гарантия «вирусности». При коротком исходнике число разных клипов может быть меньше запрошенного. Score сравнивает моменты внутри одного видео.
- Tiny — небольшая быстрая модель; текст может требовать ручной проверки. Более качественную локальную модель faster-whisper можно указать через `STREAMFORGE_MODEL`.
- Доходы, оплата показов и рекламная партнёрская сеть из ролика не реализуются локальным видеоредактором. Приложение добавляет ваш баннер; публикация в соцсетях и монетизация остаются внешними процессами.
- Загрузка платформ зависит от доступности, ограничений и версии yt-dlp. Прямые эфиры, DRM и обход авторизации не поддерживаются. При отказе загрузки используйте разрешённый локальный файл. Для YouTube/Twitch выбирается лучший единый файл со звуком; доступное качество может быть ниже максимального.
- Размытый фон сохраняет исходный кадр; центральный кроп не отслеживает лица. Полноценный монтаж, ручная коррекция субтитров, Telegram-бот и автопубликация не входят в этот выпуск.
- CPU работает без CUDA. Для NVIDIA нужны совместимые CUDA/cuBLAS/cuDNN для установленного CTranslate2; при ошибке GPU используйте CPU. Отмена Whisper завершается между выдаваемыми сегментами, поэтому может задерживаться во время вычисления.
- Аудио и редкие кадры анализируются через временные файлы. Для длинного стрима нужно свободное место: 16 kHz mono WAV занимает примерно 115 МБ/час, плюс загрузка исходника и результаты.

## Данные и диагностика

Windows: `%LOCALAPPDATA%\StreamForge`; Linux: `~/.local/share/StreamForge`.

В папке — `streamforge.db`, `studio.log`, загруженные видео. `STREAMFORGE_DATA_DIR` меняет путь. Для резервной копии закройте приложение и скопируйте папку. При открытии истории восстанавливаются настройки и результаты; исходники и экспортированные видео должны оставаться по прежним путям.

Приложение не подключается к Telegram-боту, показанному в рекламе, и не отправляет ему файлы. Локальные видео и распознавание обрабатываются на компьютере пользователя.

## Разработка

Python 3.12 x64:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python tools/prepare_model.py
.venv\Scripts\python main.py
```

Загрузка модели обращается к официальному репозиторию `Systran/faster-whisper-tiny` на Hugging Face. В сборке сохраняется точная ревизия в `assets/model/provenance.json`. Для EXE модель загружается на этапе сборки, а не на компьютере пользователя. FFmpeg поставляется wheel-пакетом imageio-ffmpeg и не требует системной установки. Фильтры субтитров работают со встроенным шрифтом DejaVu Sans (лицензия в `assets/fonts/`). Whisper основан на открытой MIT-модели OpenAI; зависимости сохраняют свои лицензии.

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
.venv\Scripts\python -m pytest -q
powershell -File build_windows.ps1
```

Выход: `dist/StreamForgeStudio.exe`. Собирать EXE нужно на Windows. GitHub Actions делает Windows-сборку и публикует её по тегам `v1.*`. Сборка включает настоящую проверку распознавания английской речи из контрольной записи faster-whisper и повторяет её **внутри собранного EXE** вместе с созданием MP4, субтитров и баннера.

## Структура

`streamforge/` содержит независимые модули анализа, загрузки, субтитров, баннеров, экспорта, SQLite, pipeline и Qt-интерфейса; `tests/` — интеграционные тесты настоящей обработки; `tools/` — подготовку модели; `assets/` — шрифт, оформление и встроенную модель сборки.
