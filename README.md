# AI Clip Studio — этап 1

Рабочее настольное приложение для Windows 10/11 x64 на Python 3.12 и PySide6.

## Скачать EXE

Готовые сборки: https://github.com/ipoteca22848/ai111/releases/latest

Скачайте **AIClipStudio.exe** из Assets и запустите. Python не требуется. Приложение не подписано сертификатом; проверяйте источник и SHA-256 сборки. Не нужно запускать от администратора.

## Реализовано

- Тёмный интерфейс с палитрой из ТЗ, адаптивными панелями и собственным графиком.
- Локальная SQLite-база проектов, статистика и активность за 7 дней по реальным данным (UTC).
- Пакетный импорт файлов через диалог и drag-and-drop в фоновом QThread.
- Проверка контейнера и чтение длительности, разрешения, FPS, размера и аудиодорожек через FFprobe, если он есть в PATH.
- При отсутствии FFprobe сохраняется путь и размер; метаданные явно помечены как недоступные.
- Поиск, переименование, удаление записей с подтверждением, просмотр сведений и открытие в системном плеере.
- Сохранение проектов и настроек между запусками. Исходники не изменяются и не копируются.
- Журнал ошибок, блокировка второго экземпляра для одной папки данных.

Это **первый этап**, а не законченный генератор клипов. Whisper, AI-рейтинг, URL-загрузка, встроенный плеер/редактор, кадрирование, баннеры, субтитры и экспорт пока не реализованы. Число клипов остаётся нулевым до реализации обработки. Для следующих этапов запланированы faster-whisper, PyTorch, OpenCV, librosa и yt-dlp; сейчас они не устанавливаются без необходимости.

## Запуск из исходников

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Для расширенных метаданных установите FFmpeg с FFprobe из доверенного источника, указанного на https://ffmpeg.org/download.html, добавьте папку bin в PATH и перезапустите приложение. EXE не содержит FFmpeg.

Данные: `%LOCALAPPDATA%\AIClipStudio` в Windows, `~/.local/share/AIClipStudio` в Linux. `AICLIP_DATA_DIR` задаёт альтернативную папку. Для резервной копии закройте приложение и скопируйте всю папку данных. Перенос исходного видео делает старую ссылку недоступной: удалите запись и импортируйте новый путь.

## Тесты и сборка Windows

```powershell
powershell -ExecutionPolicy Bypass -File build_windows.ps1
```

Скрипт устанавливает зависимости, запускает pytest и собирает `dist/AIClipStudio.exe`. EXE нужно собирать именно на Windows. GitHub Actions выполняет тесты и smoke-проверку упакованного приложения; push тега `v*` публикует файл в Releases. Workflow можно запустить вручную для артефакта без релиза.

На Linux для проверки UI без экрана: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q`.

## Архитектура и дальнейшие этапы

- `config/` — пути и настройки; `database/` — SQLite и модели.
- `core/` — получение метаданных, в дальнейшем обработка и AI.
- `workers/` — фоновые задачи; `ui/` — интерфейс; `assets/` — дизайн-система.
- Этап 2: URL-импорт, миниатюры и встроенное воспроизведение.
- Этапы 3–4: Whisper, анализ аудио/видео, объяснимый эвристический рейтинг и нарезка.
- Этапы 5–6: вертикальное кадрирование, субтитры, баннеры, редактор и пакетный экспорт.
- Этап 7: расширенные функции, оптимизация и подготовка коммерческого выпуска.
